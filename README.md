# Hiswill Iroegbulam — Portfolio

Live design language from [hiswill.vercel.app](https://hiswill.vercel.app), finished with real copy, project cards, motion, and a working contact path.

## Stack
Vite + React 18. Deploy on Vercel from this repo.

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm run preview
```

Reconnect the Vercel project `hiswill` to `Hiswill46/My-portfolio` (this repository) so https://hiswill.vercel.app picks up the new build.
